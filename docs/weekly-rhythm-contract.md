# 周节奏契约

- 节奏页是趣味面板的一部分，总开关关闭时隐藏。周选择独立于总览的查询、删除、CSV 导出范围。
- 每周固定为用户当前时区的周一零点至下周一零点。Calendar 仅在 Swift 侧生成绝对时间区间，不序列化 Calendar 对象给 Rust。
- 按本地分钟边界生成不重叠 civil-hour 段。重复小时合并同格；跳过小时标记为不存在，不能解释为零活动；半小时夏令时仍按正确的本地小时归属。
- `timeline` RPC 接收 `ranges:[{start,end}]`，最多 200 段、单段不超过 2 小时、总跨度不超过 8 天。起点分钟对齐；终点允许当前观测时刻。一次读取 minutes 表，不读取 key_histograms，不写数据库。
- 历史计数保持分钟精度：交集分钟的计数全部纳入；活动 mask 仅累加截止前已完成秒。不能宣称任意秒级输入次数筛选。
- 未来时段、时钟不存在时段、无统计记录三个状态分别表达。`observedSeconds` 是日历已过去秒数，不代表监听连续覆盖；`hasRecords` 才表示存在分钟统计。无统计记录不等于没有活动。
- 周报只用本机模板计算，标明演示、时间范围、时区和截止时间；不调用模型、不上传、不推断效率、情绪或工作场景。复制是用户主动写入剪贴板，导出在保存面板打开前冻结报告。
- 只有节奏页可见、趣味开关开启、窗口可见时请求 timeline。当周最多每 30 秒自动刷新；已结束的历史周缓存，显式刷新重新读取。请求进行期间自动刷新不会作废它；切周/离页通过代次检查丢弃过期响应。
- 查询在看板串行后台队列执行。关闭看板仍退出其进程，不增加常驻采集字段、定时查询或额外服务。

验证入口：`scripts/test-rhythm.sh`（Calendar/报告）、`scripts/test-runtime.sh`（跨语言与本地 IPC）、locked Cargo tests（SQL/边界）、release `timeline_benchmark`（临时合成年数据）。实机权限与真实输入证据独立于这些 fixture。
